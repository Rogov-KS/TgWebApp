# План настройки Telegram интеграции

## 🎯 Цель
Полная интеграция Snake Game с Telegram Web App, включая бота, backend и frontend.

## 📋 Пошаговый план

### Этап 1: Настройка Telegram бота ✅

1. **Создание бота в Telegram**

   - [ ] Сохранить токен бота

2. **Настройка Web App в BotFather**

## 🔧 Команды для быстрого старта

### 1. Настройка бота:
```bash
cd tg_bot
python setup.py
# Отредактировать .env файл
python bot.py
```

### 2. Запуск backend:
```bash
cd backend
# Создать .env с TELEGRAM_BOT_TOKEN
alembic upgrade head
uvicorn main:app --reload
```

### 3. Запуск frontend:
```bash
cd frontend
npm install
npm run dev
```

### 4. Туннелирование для разработки:
```bash
ngrok http 3000
# Использовать ngrok URL в BotFather
```
