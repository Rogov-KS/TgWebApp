# State Validation для OAuth2

## Что добавлено

### 1. StateStorage (`backend/oauth2/state_storage.py`)
Класс для управления state параметрами OAuth:
- Генерация уникальных state
- Валидация state при callback
- Автоматическая очистка истекших state
- Защита от повторного использования state

### 2. Обновленные роутеры
- **Google OAuth**: добавлена валидация state в `/oauth2/google/url` и `/oauth2/google/callback`
- **Yandex OAuth**: добавлена валидация state в `/oauth2/yandex/url` и `/oauth2/yandex/callback`

### 3. Обновленные utils
- **Google utils**: поддержка переданного state параметра
- **Yandex utils**: поддержка переданного state параметра

### 4. Автоматическая очистка
- Задача очистки истекших state каждые 5 минут
- Запуск при старте приложения

## Как это работает

1. **При запросе URL авторизации**:
   - Генерируется уникальный state
   - Сохраняется в памяти с меткой времени
   - Передается в URL авторизации

2. **При callback**:
   - Проверяется наличие state в хранилище
   - Проверяется соответствие провайдера
   - Проверяется время жизни (5 минут)
   - Проверяется, что state еще не использовался
   - State помечается как использованный

3. **Автоматическая очистка**:
   - Каждые 5 минут удаляются state старше 10 минут
   - Предотвращает утечки памяти

## Безопасность

- **Защита от CSRF**: state предотвращает атаки Cross-Site Request Forgery
- **Временные ограничения**: state истекает через 5 минут
- **Одноразовое использование**: каждый state можно использовать только один раз
- **Провайдер-специфичность**: state привязан к конкретному провайдеру

## Логирование

Все операции с state логируются:
- Генерация state
- Валидация state
- Ошибки валидации
- Очистка истекших state
