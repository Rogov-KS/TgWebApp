# Анализ ошибки SQLAlchemy

## Исходная проблема

Ошибка: `sqlalchemy.exc.InvalidRequestError: When initializing mapper Mapper[User(users)], expression 'OAuth2Token' failed to locate a name ('OAuth2Token')`

## Результаты исследования

### ❌ Не удалось воспроизвести ошибку

После создания множества минимальных примеров выяснилось, что **проблема НЕ в циклической зависимости SQLAlchemy**.

Современные версии SQLAlchemy (2.0+) корректно обрабатывают:
- Циклические зависимости между моделями
- Импорты в TYPE_CHECKING
- Строковые имена в relationship()

### ✅ Найдена реальная проблема

При попытке запуска реального кода проекта обнаружена ошибка:
```
ModuleNotFoundError: No module named 'fastapi_versioning'
```

## Выводы

1. **Циклическая зависимость SQLAlchemy** - это не проблема в современных версиях
2. **Реальная проблема** - отсутствующие зависимости или неправильная конфигурация
3. **Нужна дополнительная диагностика** - полный стек ошибки из реального проекта

## Рекомендации

1. Установить отсутствующие зависимости:
   ```bash
   pip install fastapi-versioning
   ```

2. Проверить все зависимости проекта:
   ```bash
   pip install -r requirements.txt
   ```

3. Показать полный стек ошибки для точной диагностики

4. Проверить конфигурацию и переменные окружения
